## The three-part score

Every selector gets scored into a tuple — **[id, class, element]** — counting from most to least powerful:

- **id** — `#cta` — one point per ID selector
- **class** — `.btn`, `[type="text"]`, `:hover` — one point per class, attribute, or pseudo-class selector
- **element** — `button`, `::before` — one point per type selector or pseudo-element

The universal selector (`*`) and combinators (`>`, `+`, `~`, whitespace) contribute nothing to any column.

```css
#cta               /* [1, 0, 0] */
.btn.primary       /* [0, 2, 0] */
button#cta.btn      /* [1, 1, 1] */
nav ul li a         /* [0, 0, 4] */
```

## Columns compare, they don't sum

Comparison happens **left to right**, and the first column that differs decides the winner — the remaining columns are never even considered:

```
[1, 0, 0]  vs  [0, 99, 0]   →  [1,0,0] wins (first column: 1 > 0)
[0, 2, 0]  vs  [0, 1, 5]    →  [0,2,0] wins (first column ties at 0, second: 2 > 1)
```

This is the single most common CSS misconception — developers often assume "more classes should eventually out-muscle an ID," but no number of classes ever moves the needle on the ID column.

## Ties and `!important`

If specificity ties exactly, **source order** breaks the tie — whichever rule appears later (in the same stylesheet, or in a later-loaded one) wins. `!important` doesn't skip this tiebreak process — it moves a declaration into an entirely higher-priority tier of the cascade (see The Cascade & Inheritance) *before* specificity is ever consulted. Two competing `!important` declarations still resolve by specificity, then source order, exactly like two normal declarations would — `!important` only decides which tier a declaration competes in, not how ties within that tier get broken.

## Why it matters

"Why isn't my style applying?" is almost always a specificity question. Reaching for `!important` treats the symptom; reading the competing selectors' scores finds the actual cause — usually a leftover ID selector or an overly-nested descendant chain from years-old CSS.
