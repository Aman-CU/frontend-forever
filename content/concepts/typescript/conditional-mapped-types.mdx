## Mapped types

A mapped type iterates every key `K` of an existing type `T` and produces a new value type for each:

```ts
type Readonly2<T> = {
  readonly [K in keyof T]: T[K];
};

type Nullable<T> = {
  [K in keyof T]: T[K] | null;
};

type User = { name: string; age: number };
type NullableUser = Nullable<User>;
// { name: string | null; age: number | null }
```

`keyof T` produces a union of `T`'s property names (`"name" | "age"`), and `[K in ...]` maps over that union the same way a `for...of` maps over an array — once per key, with `T[K]` looking up that key's original value type.

## Conditional types

A conditional type branches based on whether one type is assignable to another:

```ts
type IsString<T> = T extends string ? true : false;

type A = IsString<"hello">; // true
type B = IsString<42>;      // false
```

This is exactly how `ReturnType<T>` works under the hood — extract a function's return type by matching against a generic pattern:

```ts
type MyReturnType<T> = T extends (...args: never[]) => infer R ? R : never;

function greet(): string { return "hi"; }
type G = MyReturnType<typeof greet>; // string
```

`infer R` introduces a new type variable inside the conditional's `extends` clause, capturing whatever type appears in that position — here, the function's actual return type.

## Combining them: how Partial\<T\> is built

Built-in utility types are just mapped (and sometimes conditional) types with a name:

```ts
type MyPartial<T> = {
  [K in keyof T]?: T[K];
};
```

Every property in `T` gets mapped to itself, but with `?` added — the entire `Partial<T>` utility type, in three lines, no special compiler magic involved.

## Why it matters

Once mapped and conditional types click, the built-in utility types (`Partial`, `Pick`, `Required`, `ReturnType`, `Exclude`) stop looking like a fixed list to memorize and start looking like small, composable programs written in the type system — and it becomes possible to write a project's own derived types the same way, instead of hand-maintaining a second type that has to be kept in sync by hand.
