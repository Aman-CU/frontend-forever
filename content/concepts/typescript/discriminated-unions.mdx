## The shape of a discriminated union

Every variant shares one field with a distinct literal type — commonly `type` or `kind`:

```ts
type Circle = { kind: "circle"; radius: number };
type Rectangle = { kind: "rectangle"; width: number; height: number };
type Shape = Circle | Rectangle;
```

`kind` is the **discriminant** — its value uniquely identifies which variant a given `Shape` actually is.

## Narrowing with switch

Checking the discriminant narrows the entire object, not just that field:

```ts
function area(shape: Shape): number {
  switch (shape.kind) {
    case "circle":
      return Math.PI * shape.radius ** 2; // shape narrowed to Circle
    case "rectangle":
      return shape.width * shape.height; // shape narrowed to Rectangle
  }
}
```

Inside the `"circle"` case, `shape.radius` is accessible with no cast — TypeScript has already proven `shape` can only be a `Circle` there, because `kind` can't simultaneously be `"circle"` and `"rectangle"`.

## Exhaustiveness checking

Pairing a discriminated union with a `default` case that assigns to a `never`-typed variable turns "I forgot to handle a variant" into a compile error, not a silent runtime gap:

```ts
function assertNever(value: never): never {
  throw new Error(`Unhandled variant: ${JSON.stringify(value)}`);
}

function area(shape: Shape): number {
  switch (shape.kind) {
    case "circle": return Math.PI * shape.radius ** 2;
    case "rectangle": return shape.width * shape.height;
    default: return assertNever(shape); // compile error if a variant is missing
  }
}
```

Add a third `Triangle` variant to `Shape` without adding its case here, and `assertNever(shape)` no longer compiles — `shape` in the `default` branch is no longer narrowed to `never`, because there's an unhandled possibility left over. The bug surfaces at compile time, in the exact function that needed updating, instead of a missing-case bug shipping to production.

## Redux-style reducers — the canonical example

Discriminated unions are the reason a Redux-style reducer can safely branch on `action.type` and get full type safety on every action's specific payload:

```ts
type Action =
  | { type: "increment" }
  | { type: "decrement" }
  | { type: "set"; value: number };

function reducer(state: number, action: Action): number {
  switch (action.type) {
    case "increment": return state + 1;
    case "decrement": return state - 1;
    case "set": return action.value; // action.value only exists on "set"
  }
}
```

## Why it matters

Discriminated unions turn "which variant is this, and what fields does it actually have" from a runtime guessing game into something the compiler verifies for you at every call site — and exhaustiveness checking means adding a new variant anywhere in a large codebase gets flagged everywhere it wasn't handled, instead of silently falling through.
